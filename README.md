# scale_gad7 — Generalized Anxiety Disorder Scale

A 7-item self-report scale for screening for generalized anxiety disorder and assessing anxiety severity. Each item rated 0–3 over the past 2 weeks.

- **Instrument:** GAD-7 (GAD-7) · Anxiety Screening
- **7 items** (see `data/gad7.json`).
- **Scoring:** 0–4: minimal; 5–9: mild; 10–14: moderate; 15–21: severe. Cut-off ≥10 for GAD diagnosis (sensitivity 89%, specificity 82%).
